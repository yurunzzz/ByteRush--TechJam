02用户构成锁死了 nDCG

指标先按用户算再平均，所以"谁进平均、谁被剔除"由数据说了算，模型改不了。

63.7%有区分度 · 进 GAUC
27.1%全负 · nDCG=0
9.2%全正 · GAUC 不计

27.1% 的用户名下一个 long_view=1 都没有 —— 他们的 nDCG@5 恒为 0 却计入平均，直接把 nDCG 上限从 1.0 压到 0.729（这就是上节 nDCG 空间小的原因）。另有 9.2% 全正用户被 GAUC 排除（AUC 在单一类别上无定义）。这是口径决定的损失，模型救不了。

05建模优先级

每条锚定上面某节观察，只给动作与新增理由，不复述已列数字。

先做

Pairwise / BPR 目标函数

baseline 用 pointwise logloss，评测却是排序指标；对齐两者是最大且最直接的杠杆，正对 §01 里 GAUC 那侧的空间。

先做

tab 交叉特征

§04 的 tab 与 user/video 交叉能改变用户内相对序；纯用户侧一阶项则无效 —— 它给一个用户的每条曝光加同一常数，动不了排序。

再看

因果时序特征 / recency 加权

漂移温和，收益中等。历史 long_view 率、近 N 次行为池化须严格用更早事件构造，禁止未来信息。

再看

多任务：click / 完播

日志含稠密辅助反馈可作辅助任务；long_view 仍是唯一选型目标，逐个加并做负迁移消融。

放弃

冷启动 / 内容兜底

§03：没有冷启动样本可救。

放弃

死磕 nDCG / 单纯扩容

§02 的 nDCG 天花板是结构性的；加宽 embedding 8→16→32 经组织方消融证明无效。
